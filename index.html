🎬 Movies API

A simple, free, and publicly accessible movies API hosted on GitHub Pages

📚 About

This API combines static JSON snapshots (via GitHub Pages) with dynamic Vercel serverless functions so you can fetch, filter, and mutate movie data in real time. The Irish Box Office top 10 refreshes automatically every Monday morning using GitHub Actions.

💻 Usage Examples (Dynamic)

JavaScript (Fetch API)

const apiBase = 'https://your-vercel-project.vercel.app';

// Fetch all movies (GET /api/movies)
fetch(`${apiBase}/api/movies`)
    .then(res => res.json())
    .then(console.log);

// Filter movies (GET /api/movies?genre=Action&minRating=8.5)
fetch(`${apiBase}/api/movies?genre=Action&minRating=8.5`)
    .then(res => res.json())
    .then(console.log);

// Add a movie (POST /api/movies)
fetch(`${apiBase}/api/movies`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        title: 'My Movie',
        year: 2025,
        director: 'Me',
        genre: ['Adventure'],
        rating: 8.1
    })
}).then(res => res.json()).then(console.log);

// Irish box office (GET /api/boxoffice)
fetch(`${apiBase}/api/boxoffice`)
    .then(res => res.json())
    .then(console.log);
