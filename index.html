🎬 Movies API

A simple, free, and publicly accessible movies API hosted on GitHub Pages

📚 About

This is a simple REST API that provides information about popular movies. All data is served as static JSON files, making it fast, reliable, and completely free to use. No authentication required!

💻 Usage Example

JavaScript (Fetch API)

// Fetch all movies
fetch('https://[your-username].github.io/public-hosted-api/api/movies.json')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error('Error:', error));

// Fetch genres
fetch('https://[your-username].github.io/public-hosted-api/api/genres.json')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error('Error:', error));
